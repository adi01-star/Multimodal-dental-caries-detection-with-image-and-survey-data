# Multimodal Dental Caries Detection and Risk Prediction

## Overview

This app now supports **three prediction modes**, matching the project's
two independent pipelines and their late-fusion combination:

1. **Image Only** - the original YOLOv8 pipeline detects and localizes
   visible carious lesions in intraoral dental photos.
2. **Survey Only** - a new lifestyle/behavioral pipeline predicts caries
   risk from structured questionnaire data (diet, sugar consumption,
   brushing habits, dental visit frequency, fluoride exposure, smoking,
   and demographics), using the best of Logistic Regression, Random
   Forest, and XGBoost.
3. **Combined** - a late-fusion score that averages the two pipelines'
   probabilities, to check whether image evidence and lifestyle risk
   factors are complementary.

This is a **screening / risk-assessment tool**, not a clinical diagnostic
or treatment system.

## Setup

1. **Clone the repository** and open the project directory:
   ```bash
   git clone https://github.com/adi01-star/Multimodal-dental-caries-detection-with-image-and-survey-data.git
   cd Multimodal-dental-caries-detection-with-image-and-survey-data
   ```

2. **Install dependencies** (Python 3.10+):
   ```bash
   pip install -r requirements.txt
   ```

3. **Train the lifestyle/survey pipeline.**
   No real population dataset is bundled with this repo, so start with the
   synthetic data generator to get the pipeline running end-to-end, then
   swap in a real dataset (e.g. an NHANES-style oral health survey, a
   national dental epidemiology dataset, or de-identified clinic intake
   data) once available:
   ```bash
   python training/generate_synthetic_lifestyle_data.py --n 3000
   python training/train_lifestyle_model.py
   ```
   This prints a comparison of Logistic Regression, Random Forest, and
   XGBoost (cross-validated ROC-AUC, accuracy, precision, recall, F1),
   picks the best model, and saves it to `data/lifestyle_model.pkl`.

   To use your own dataset instead: give your CSV the same column names as
   `data/feature_schema.json` (or edit the schema to match your columns),
   then run:
   ```bash
   python training/train_lifestyle_model.py --data path/to/your_survey_data.csv
   ```

4. **Run the app**:
   ```bash
   python app/gradio-app.py
   ```
   Open `http://localhost:7860`. If the lifestyle model hasn't been
   trained yet, the **Image Only** tab still works; **Survey Only** and
   **Combined** will show a message telling you to run step 3.

5. **Docker (optional)** - train the lifestyle model *before* building, so
   `data/lifestyle_model.pkl` exists to be copied into the image:
   ```bash
   docker build -t caries-detection-app .
   docker run -p 7860:7860 caries-detection-app
   ```

## Evaluating all three levels together

Once you have a **paired** dataset - i.e., cases where you have both a
dental image *and* survey answers *and* a confirmed ground-truth label for
the same subject - you can compare image-only, lifestyle-only, and
combined performance directly:

```bash
python training/evaluate_pipelines.py --data data/paired_eval_data.csv --image-weight 0.5
```

The CSV needs an `image_path` column, one column per field in
`data/feature_schema.json`, and a `label` column (1 = caries confirmed).
The script reports ROC-AUC, accuracy, precision, recall, and F1 for each
of the three levels and saves them to `data/pipeline_evaluation.json`.

## Late fusion

`app/fusion.py` implements two strategies:

- **Weighted average** (default): `combined = w * image_prob + (1-w) * lifestyle_prob`.
  `w` is adjustable in the Combined tab's slider, or via
  `--image-weight` in `evaluate_pipelines.py`. Start at 0.5 and tune once
  you have paired validation data showing which modality is more reliable.
- **Meta-model (stacking)**: `fusion.train_meta_model_fusion()` fits a small
  logistic regression on `[image_prob, lifestyle_prob] -> label` using a
  paired dataset, letting the data decide how to weight each pipeline
  instead of hand-picking a weight.

## Tech Stack

- **Python**
- **Ultralytics YOLO** - image pipeline (caries detection/localization)
- **scikit-learn, XGBoost** - lifestyle pipeline (risk classification)
